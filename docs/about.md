# About Conventional Commit Spec

## Who maintains it

Conventional Commit Spec is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/conventional-commit-spec](https://github.com/mediuswareltd/conventional-commit-spec).

## Why it exists

Mandatory conventional-commit, branching, PR, and release standards for Mediusware contributors.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/conventional-commit-spec/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.

## Contributing

Issues and pull requests are welcome. Follow Mediusware conventional-commit standards when you contribute.
