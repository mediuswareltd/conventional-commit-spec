# Guide

## What it is

Mandatory conventional-commit, branching, PR, and release standards for Mediusware contributors.

## Stack

`Git`, `Conventional Commits`, `CI`

## Capabilities

### Branching strategy

main / staging / dev with clear promotion rules.

### Commit standards

Conventional types, length limits, ownership.

### PR & merge policy

Review, rebase, conflict, and force-push rules.

### Release hygiene

CI sync requirements and dependency guidance.
